Praktikum Minggu 1

Tujuan

Praktikum ini bertujuan untuk menyiapkan aplikasi yang dibutuhkan untuk Flutter seperti Git, VS Code, Flutter SDK, dan Android Studio.

Fitur Utama

Aplikasi yang dibuat adalah profil mahasiswa sederhana yang berisi nama, NIM, dan informasi tambahan.

Stack Teknologi

* Flutter
* Dart
* Android Studio
* VS Code

Cara Menjalankan

1. Buka terminal di folder aplikasi.
2. Masuk ke folder project dengan cd my_first_app.
3. Jalankan dengan perintah flutter run.
4. Jika ada perubahan kode bisa tekan r untuk hot reload.

Hasil yang Dicapai

Flutter doctor berhasil dijalankan dan device juga sudah terdeteksi. Tampilan bawaan Flutter sudah diubah menjadi halaman profil mahasiswa. Screenshot aplikasi juga sudah disimpan di folder screenshots.

Kendala
